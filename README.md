# 퇴근 요정

바탕화면 캐릭터와 함께 쓰는 근무 타이머입니다.

[최신 배포 파일 다운로드](https://github.com/hobbangc/offwork-fairy-releases/releases/latest)

- **Windows x64**에서 ZIP 전체를 압축 해제하고 `퇴근 요정.exe`를 실행하세요.
- **Ubuntu 24.04 amd64**에서 `.deb` 파일을 설치하고 앱 메뉴에서 **퇴근 요정**을 실행하세요. 터미널에서는 `sudo apt install ./OffworkFairy-ubuntu-amd64.deb`로 설치할 수 있습니다.
- 캐릭터를 우클릭하고 **정보 → 업데이트 확인**에서 새 버전을 확인할 수 있습니다. 새 파일을 받으면 실행 중인 앱을 닫은 뒤 설치하세요.
